Terraform Components	
Component	Meaning
Terraform CLI	Tool/command used to run Terraform
Provider	Connects Terraform to AWS, Azure, GCP, etc.
Resource	The infrastructure we want to create, e.g. EC2, S3
Configuration (.tf)	File where we write Terraform code
Variables	Store values that can change
Outputs	Display useful information after deployment
State File	Terraform's record of what infrastructure it manages
Backend	Where Terraform state is stored
Module	Reusable Terraform code
Terraform Registry	Place to find providers and modules
